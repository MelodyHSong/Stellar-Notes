## ☆ [1.0.0] - 2026-09-05

### Added
- **Initial Standalone Release**: Migrated Stellar-Notes to its own dedicated repository.
- **Star & Pin Priority**: Pin critical notes to the top of the sidebar catalog.
- **Galactic Search**: Real-time debounced filtering across note titles and content previews.
- **Cosmic Audio (Voice Narration)**: Built-in voice reading engine leveraging Windows SAPI (`Ctrl + Space`).
- **Windows Explorer Context Menu**: Seamlessly open `.md`, `.markdown`, `.txt`, and `.note` files directly via right-click.
- **Spaceship Console UI**: Obsidian console theme (`#11141c`) with glowing celestial amber stars and starlight typography.
- **Dual-Save System**: Continuous background autosave paired with manual `Ctrl + S` disk sync.
- **Zero-Admin Installer**: HKCU registry setup without requiring UAC elevation.
- **Standalone Builder**: PyInstaller spec and 1-click batch scripts for compiling single-file Windows binaries.
- **Automated CI/CD**: GitHub Actions workflow for building release executables.
